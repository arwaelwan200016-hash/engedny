نقل بيانات انجدني إلى Supabase

هننقل البيانات بدون كلمة مرور أو رابط اتصال.

  1. اضغطي الزر أدناه.
  2. في الصفحة التي ستفتح: اضغطي Ctrl + A ثم Ctrl + C.
  3. ارجعي إلى Supabase SQL Editor، افتحي New query، ثم Ctrl + V وبعدها Run.

استخدميه مرة واحدة الآن فقط؛ لأنه يستبدل بيانات جداول Engedny الموجودة في Supabase.
